# CVE-2025-71330 in image-size 1.2.1 (Denial of Service via crafted ICNS buffer)

**ID:** vuln-0006
**Severity:** HIGH

**Ecosystem:** npm

**Introduced By:** metro@0.83.3
**Dependency Chain:** metro@0.83.3 > image-size@1.2.1
**CVE:** CVE-2025-71330
**CVSS:** 7.5
**Fix Effort:** Low

## Description

The `image-size` package version **1.2.1** is vulnerable to **CVE-2025-71330**, a denial of service vulnerability affecting the ICNS (Apple Icon) parser. Attackers can permanently block the Node.js event loop by supplying a specially crafted ICNS image buffer containing valid magic bytes and a **zero-valued entry length field**, triggering an infinite loop as the offset never advances.

## Evidence

**Advisory evidence:** `CVE-2025-71330` applies to `image-size` at installed version `1.2.1`.

**Transitive dependency:** introduced by the direct dependency `metro@0.83.3`.

**Dependency chain:** `metro@0.83.3 > image-size@1.2.1`

**Usage analysis:** imported by application code; affected API usage unconfirmed. The `image-size` package is imported and used by Metro bundler (confirmed transitive dependency in `pnpm-lock.yaml`). Metro processes image assets during React Native bundling, including ICNS files for iOS/macOS builds. Static analysis confirmed no direct application code imports: `rg "image-size|imageSize" -t web -l` returned no results, indicating usage is limited to the build toolchain. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

Similar to CVE-2025-71329, this vulnerability allows denial of service via crafted ICNS image files during the React Native build process. The Metro bundler processes image assets (including ICNS files on macOS builds) and will hang indefinitely if a malicious ICNS file is encountered. This can block mobile application builds, updates, and CI/CD pipelines.

## Remediation

Upgrade the `metro` dependency chain to a version that resolves `image-size` to **2.0.3 or later** (when available). Implement image validation and sanitization in the build pipeline to reject malformed ICNS files. Consider restricting accepted image formats if ICNS support is not required.

## Assumptions

Exploitation requires an attacker to introduce malicious ICNS files into the build process. The vulnerability affects the development/CI environment where Metro processes image assets. Risk is elevated if untrusted image assets are processed during builds (e.g., user-uploaded icons or third-party asset libraries).
