# CVE-2025-71329 in image-size 1.2.1 (Denial of Service via crafted JXL/HEIF buffer)

**ID:** vuln-0005
**Severity:** HIGH
**Found:** 2026-08-25 06:18:10 UTC
**Target:** /workspace/CareCliQV2
**Package:** image-size
**Ecosystem:** npm
**Installed Version:** 1.2.1
**Introduced By:** metro@0.83.3
**Dependency Chain:** metro@0.83.3 > image-size@1.2.1
**CVE:** CVE-2025-71329
**CVSS:** 7.5
**Fix Effort:** Low

## Description

The `image-size` package version **1.2.1** is vulnerable to **CVE-2025-71329**, a denial of service vulnerability that allows attackers to permanently block the Node.js event loop. The vulnerability exists in the JXL and HEIF image parsers, where a specially crafted image buffer with a **zero-valued size field** in a recognized box-type triggers an infinite loop, causing the application to hang indefinitely.

## Evidence

**Advisory evidence:** `CVE-2025-71329` applies to `image-size` at installed version `1.2.1`.

**Transitive dependency:** introduced by the direct dependency `metro@0.83.3`.

**Dependency chain:** `metro@0.83.3 > image-size@1.2.1`

**Usage analysis:** imported by application code; affected API usage unconfirmed. The `image-size` package is imported and used by Metro bundler (confirmed transitive dependency in `pnpm-lock.yaml`). Metro is the React Native build tool that processes image assets during the bundling phase. However, direct application code does not import `image-size` — it is used exclusively by the build toolchain. Static search confirmed no direct imports: `rg "image-size|imageSize" -t web -l` returned no results in application source code. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

An attacker who can supply crafted image files to the application can trigger a permanent denial of service by causing the Node.js event loop to hang in an infinite loop. This affects the **React Native mobile application** build process via the Metro bundler, which uses `image-size` as a transitive dependency. While this primarily impacts the build/development pipeline rather than production runtime, it can block mobile app builds and updates.

## Remediation

Upgrade the `metro` dependency chain to a version that resolves `image-size` to **2.0.3 or later** (when available) which includes the fix for the infinite loop vulnerability. Monitor the upstream issue at `github.com/image-size/image-size/pull/439` for patch availability. As a workaround, validate and sanitize image files before processing during builds.

## Assumptions

This vulnerability affects the mobile application build toolchain (Metro bundler) rather than runtime code. Exploitation requires an attacker to inject malicious image files into the build pipeline. The vulnerability is present in the development/CI environment where Metro processes image assets during bundling.
