Multilingual compliance — the differentiator
The pipeline: any language → compliant English note
This is the feature that no competitor offers. The worker thinks, speaks, and documents in their first language. CareScribe handles the translation AND the compliance formatting in a single step. The compliance engine then runs on the English output — not the source language.

1
Worker speaks or types in any language
Web Speech API transcribes voice. Language is auto-detected. Worker sees the transcription in their own language in the input field.

2
Claude translates AND reformats in one call
Single API call: translate from [detected language] to English AND reformat as a compliant NDIS progress note. Not two steps — one. This keeps latency low and cost manageable.

3
Compliance engine runs on the English output
The 12 rules and 5 RP categories run on the translated English note. The source language is stored as session.input_language for audit trail — it is never the primary record.

4
The English note is the legal record. The source language is the audit trail.
The NDIS requires English documentation. The source language input is stored for audit transparency — it proves the note was genuinely produced by this worker describing this session.
