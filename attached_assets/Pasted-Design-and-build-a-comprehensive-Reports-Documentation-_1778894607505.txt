Design and build a comprehensive “Reports & Documentation” module for CareScribe — an AI-powered operational compliance platform for NDIS providers.

IMPORTANT CONTEXT:
CareScribe is NOT a generic CRM or rostering platform.
It is a real-time compliance operating system focused on:
- Session-live workflows
- Participant-focused care delivery
- Daily operational compliance
- Audit readiness
- AI-assisted documentation
- Frontline support workers and coordinators

The Reports & Documentation area must feel:
- operational
- compliance-first
- minimal cognitive overload
- audit-ready
- professional and healthcare-grade
- mobile-friendly
- task-oriented

DO NOT design this like a traditional enterprise admin dashboard with cluttered tables and excessive filters.

---------------------------------------------------
CORE UX PRINCIPLES
---------------------------------------------------

1. No modal-heavy workflows
- Every major action opens as a full page or side panel
- Users must always know where they are
- Include back navigation
- Maintain context from previous screen

2. Session-first workflow
Reports and documentation should connect directly to:
- today’s sessions
- participant care
- incidents
- incomplete tasks
- compliance gaps

3. Compliance visibility everywhere
Every document/report should visually indicate:
- complete
- pending
- missing info
- audit risk
- requires review
- signed off

4. AI should feel assistive, not gimmicky
Avoid “chatbot-looking” UI.
AI should quietly assist with:
- note structuring
- compliance checks
- missing details
- summary generation
- risk detection
- wording improvements

---------------------------------------------------
MAIN REPORTS & DOCUMENTATION STRUCTURE
---------------------------------------------------

Create these primary sections:

1. Documentation Hub
2. Session Reports
3. Incident Reports
4. Participant Notes
5. Compliance Reports
6. Audit Readiness
7. AI Insights & Flags
8. Templates & Forms
9. Export Center

---------------------------------------------------
1. DOCUMENTATION HUB
---------------------------------------------------

Purpose:
A central operational workspace showing all documentation status across the organization.

Include:
- Missing documentation alerts
- Incomplete session notes
- Unsigned reports
- Overdue incident follow-ups
- Expiring compliance documents
- Daily completion progress
- AI compliance warnings
- Quick actions

UI Requirements:
- Clean card/grid layout
- Prioritize urgent actions first
- Minimal table usage
- Use timeline/activity-feed patterns
- Status chips with colors
- Sticky summary header

Top summary cards:
- Sessions needing documentation
- Audit risks detected
- Reports pending review
- Completed today
- Compliance score
- Incident follow-ups

---------------------------------------------------
2. SESSION REPORTS
---------------------------------------------------

Purpose:
Operational reporting for daily support sessions.

Features:
- Session timeline
- Progress notes
- Goal tracking
- Task completion
- Checklists
- Worker observations
- Medication logs
- Behavioral observations
- Shift summary
- Attachments/photos/files

- Suggest compliance improvements
- Highlight missing evidence

Session > Documentation > Review > Submit > Audit-ready

UI Requirements:
- Full-page session workspace
- Participant context pinned on side
- Timeline-style interaction
- Auto-save
- “Audit readiness” indicator
- Smart prompts during note writing

---------------------------------------------------
DESIGN DIRECTION
---------------------------------------------------

Visual Style:
- Modern healthcare SaaS
- Calm and trustworthy
- Soft cards
- Spacious layouts
- Clear hierarchy
- Minimal clutter
- Premium operational software feel

Avoid:
- Generic AI visuals
- Neon AI icons
- Overly corporate ERP style
- Dense tables everywhere
- Complex navigation
- Too many colors

Preferred UX:
- Sticky action bars
- Timeline interactions
- Smart summaries
- Progressive disclosure
- Contextual AI assistance
- Mobile responsiveness

---------------------------------------------------
KEY DIFFERENTIATOR
---------------------------------------------------

The Reports & Documentation module should reinforce this message:

“CareScribe ensures every session, task, and participant interaction is continuously audit-ready in real time.”

The experience should feel proactive, not reactive.
