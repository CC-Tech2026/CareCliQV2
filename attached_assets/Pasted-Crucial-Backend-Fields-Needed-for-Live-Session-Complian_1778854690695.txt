Crucial Backend Fields Needed for Live Session Compliance
When a practitioner starts a live session, the backend needs to deliver an optimization payload containing context markers. Here are the specific parameters your endpoint should return to empower the front-end chat engine:

A. The "Goal Rules Matrix" (Critical for NDIS Claims)
When a support worker writes text or records a voice note, your backend AI parser needs to know exactly what goals it is tracking to confirm compliance. Your API response must provide:

goals.id: For mapping database record associations.

goals.description: The actual text of the participant's goal (e.g., "Improve community mobility via modified vehicle operations").

goals.category: Maps natively to NDIS categories (e.g., Capacity Building).

B. Risk Assessments & Critical Alerts
To ensure safe practices during audits, safety and risk-reduction strategies must be immediately visible to the worker.

risk_level: High, Medium, Low.

triggers: (e.g., "Sensory overload in crowded environments").

management_plan: Immediate steps the worker must perform to maintain alignment with the NDIS Quality and Safeguards Commission rules.

4. How the Backend Powers the Real-Time Compliance Score
When the user enters text or finishes a voice transcription, the frontend hits an assessment endpoint. The backend processes the text using a lightweight validation matrix to instantly compute the score:

Plaintext
Score Calculation Logic Matrix:
+------------------------------------+--------+
| Requirement Metric Verified        | Weight |
+------------------------------------+--------+
| Verified Timestamp & GPS Check-In  |  +25%  |
| Semantic connection to NDIS Goal   |  +35%  |
| Documented Support Outcome Text    |  +25%  |
| Next-step / Routine Action Logged  |  +15%  |
+------------------------------------+--------+
| Total Potential Score              |  100%  |
If the score returns at 75% or greater, the backend marks the entry row flag as is_ready_for_billing = true. This allows automated extraction tools to instantly pull your audit logs and generate cleanly formatted invoices for the NDIA myplace provider portal.
