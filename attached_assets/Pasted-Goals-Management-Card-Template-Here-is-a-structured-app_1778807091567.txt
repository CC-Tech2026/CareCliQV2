Goals Management Card Template
Here is a structured approach for the GoalsManagementCard. This component focuses on linking clinical progress to specific NDIS goals, which is essential for auditing and reporting.

TypeScript
interface GoalsManagementCardProps {
  participantId: string;
  goals: NDISGoal[];
  onRefresh: () => void;
}

export function GoalsManagementCard({ participantId, goals, onRefresh }: GoalsManagementCardProps) {
  return (
    <div className="rounded-2xl border bg-white p-6 shadow-sm">
      <div className="flex items-center justify-between mb-6">
        <div className="flex items-center gap-2">
          <div className="p-2 bg-indigo-50 rounded-lg">
            <Target className="h-5 w-5 text-indigo-600" />
          </div>
          <div>
            <h3 className="text-lg font-semibold text-slate-900">NDIS Goals</h3>
            <p className="text-sm text-slate-500">Track progress against plan objectives</p>
          </div>
        </div>
        <Button variant="outline" size="sm" className="gap-2">
          <Plus className="h-4 w-4" /> Add Goal
        </Button>
      </div>

      <div className="space-y-4">
        {goals.length === 0 ? (
          <div className="text-center py-8 border-2 border-dashed rounded-xl">
            <p className="text-sm text-slate-400">No goals linked to this plan yet.</p>
          </div>
        ) : (
          goals.map((goal) => (
            <div key={goal.id} className="p-4 rounded-xl border bg-slate-50/30 hover:bg-slate-50 transition-colors">
              <div className="flex justify-between items-start mb-3">
                <Badge variant="secondary" className="bg-white border-slate-200 text-slate-600">
                  {goal.category || "General"}
                </Badge>
                <div className="flex items-center gap-1 text-[11px] font-medium text-slate-500">
                  <Clock className="h-3 w-3" />
                  Target: {safeFormat(goal.target_date)}
                </div>
              </div>
              
              <p className="text-sm font-medium text-slate-800 mb-4">
                {goal.description}
              </p>

              <div className="flex items-center gap-4">
                <div className="flex-1">
                  <div className="flex justify-between text-[11px] mb-1">
                    <span className="text-slate-500">Progress</span>
                    <span className="text-indigo-600 font-bold">{goal.progress_percentage}%</span>
                  </div>
                  <Progress value={goal.progress_percentage} className="h-1.5" />
                </div>
                <Button size="icon" variant="ghost" className="h-8 w-8 text-slate-400 hover:text-indigo-600">
                  <TrendingUp className="h-4 w-4" />
                </Button>
              </div>
            </div>
          ))
        )}
      </div>
    </div>
  );
}
Key Functional Additions to Consider:
Goal Categorization: NDIS goals usually fall under "Capacity Building," "Core," or "Capital." Adding a color-coded badge for these helps therapists quickly identify which sessions apply to which funding bucket.

Progress Indicators: Use the TrendingUp icon to open a small "History" popover or drawer showing how the percentage has changed over the last 3 months.

Session Linking: When a therapist writes a note, providing a multi-select dropdown to "Tag NDIS Goals" will allow your AISummary hook to later generate reports specifically showing how a session met Goal X or Goal Y.
